# Contributing

Contributions are always welcome and are greatly appreciated.

If you believe you've found a bug, please provide detailed steps of reproduction and state the current behavior vs. the expected behavior.

If you'd like to see a feature or an enhancement please open an issue with a clear title and description of what the feature is and why it would be beneficial.


## Making Changes

Before submitting a pull requestL
1. Add or update tests for behavior you change or introduce.
2. Run `go test ./...` and make sure all tests pass.
3. Run `golangci-lint run` and ensure there are no linter errors.

Thanks for helping improve subgo!
